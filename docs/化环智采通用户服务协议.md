## 二、服务内容

本小程序提供以下服务：

1. **采购指南智能匹配**：您选择采购类目并输入预算金额后，系统根据类目和预算区间自动匹配并展示对应的采购指南；
2. **指南详情查看与附件下载**：查看图文指南内容并下载相关附件；
3. **收藏与留言**：收藏常用指南，提交留言、建议或问题；
4. **消息通知**：通过站内消息及微信订阅消息接收系统公告和指南更新通知；
5. **管理功能**：由我们授权的管理人员对类目、价格区间、指南、用户名单及消息进行维护。

我们有权根据业务需要调整、增加或停止部分服务内容，并通过小程序内公告等方式通知您。
