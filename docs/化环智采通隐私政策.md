# 化环智采通小程序隐私政策

**更新日期：** 2026年8月26日

**生效日期：** 2026年8月26日

## 一、引言

「化环智采通」微信小程序（以下简称"本小程序"）由深圳大学化学与环境工程学院（以下简称"我们"）开发并运营，为您提供院内采购指南智能匹配、查看、收藏与消息通知等服务。

我们深知个人信息对您的重要性，将按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规及微信小程序平台的相关规范，收集、使用、存储和保护您的个人信息。本政策将向您说明我们收集、使用、存储您个人信息的目的、方式和范围，以及您享有的相关权利。

请您在使用本小程序前仔细阅读并充分理解本政策。**您勾选"我已阅读并同意《用户服务协议》和《隐私政策》"并完成登录，即表示您已同意我们按照本政策处理您的个人信息。**

## 二、我们收集哪些信息

### （一）您主动提供的信息

1. **姓名**：用于登录时核验您的身份，确认您是否在授权名单内；
2. **手机号码**：用于登录身份核验、账号识别及后续消息通知；
3. **留言内容**：您在"留言板"提交的意见、建议或问题；
4. **订阅选择**：您在小程序内选择是否接收公告、指南更新等微信订阅消息。

### （二）我们在您使用服务过程中收集的信息

1. **微信 OpenID**：通过微信平台获取的唯一用户标识，用于自动登录、识别账号身份以及向您发送订阅消息；
2. **登录与使用记录**：包括您的登录时间（最近登录时间）以及使用小程序产生的操作记录；
3. **收藏记录**：您收藏的指南信息；
4. **消息记录**：我们向您发送的站内消息及订阅消息记录；
5. **管理员操作日志**：授权管理员在后台维护用户、类目、指南等信息的操作记录（含操作人、操作时间、操作内容）。

### （三）管理员维护的信息

授权管理员通过后台导入或编辑的用户名单信息（姓名、手机号），其中可能包含您的信息，用于身份校验和登录授权。

### （四）敏感信息说明

您的**手机号码**属于法律意义上的个人信息，我们仅在实现上述服务功能所必需的范围内收集、使用和存储，并将采取加密等安全措施予以保护。

## 三、我们如何使用您的信息

我们收集您的个人信息，仅用于以下明确的目的：

| 信息类型 | 使用目的 | 使用方式 |
| --- | --- | --- |
| 姓名、手机号 | 登录身份核验，确认您是否在授权名单内；建立账号身份 | 登录时提交至云端与授权名单比对 |
| 微信 OpenID | 自动登录、识别账号身份 | 微信平台返回后与您的账号绑定 |
| 手机号、OpenID | 接收系统公告、指南更新等通知 | 用于发送站内消息和微信订阅消息 |
| 姓名、手机号 | 管理员用户管理 | 授权管理员查询、编辑授权名单 |
| 收藏记录 | 保存您的收藏，便于快速查看 | 关联至您的账号并存储 |
| 留言内容 | 接收并处理您的意见、建议 | 展示在留言板并存储 |
| 登录、操作记录 | 服务安全审计、问题排查 | 存储于云端数据库 |

我们**不会**将您的个人信息用于与本小程序服务无关的用途，**不会**向任何第三方出售、出租或以其他方式提供给第三方用于商业营销，法律法规另有规定或您另行同意的除外。

## 四、信息的存储

1. **存储位置**：您的个人信息存储于微信云开发提供的云数据库和云存储中（由腾讯公司提供，服务器位于中华人民共和国境内）；
2. **本地缓存**：登录成功后，我们会在您的设备本地缓存登录凭证、姓名和手机号等信息，用于自动登录和页面展示；
3. **存储期限**：我们仅在为您提供本小程序服务所必需的期限内保留您的个人信息，即您的账号有效期内；法律法规另有规定需要保存的（如审计、安全事件调查等），从其规定。您的账号被删除或您申请注销后，我们将依法删除或匿名化处理您的个人信息。

## 五、信息的共享、转让与公开披露

### （一）共享

除以下情形外，我们不会与任何第三方共享您的个人信息：

1. **微信平台及云开发服务商（腾讯）**：为提供微信登录、订阅消息、云数据库、云存储等基础能力所必需；
2. **获得您的明确同意**；
3. **法律法规规定**：根据法律法规、监管要求或有权机关的要求必须提供的。

### （二）转让

我们不会将您的个人信息转让给任何第三方，但发生合并、分立、解散、被收购等情形且涉及个人信息转让的除外；在此情形下，我们会要求继受方继续受本政策约束，或重新征得您的同意。

### （三）公开披露

我们不会公开披露您的个人信息，但法律法规规定或经您明确同意的除外。

## 六、信息的安全保护

1. 我们采取符合行业标准的安全防护措施保护您的个人信息，包括但不限于：访问控制、权限管理、传输加密（HTTPS）、操作日志审计等；
2. 我们仅授权必要的工作人员在必要范围内接触您的个人信息，并要求其履行保密义务；
3. 如不幸发生个人信息安全事件，我们将按照法律法规要求及时告知您，并向有关主管部门报告。

## 七、您的权利

根据法律法规，您享有以下权利：

1. **查询与更正**：您可以通过"我的"页面查看您当前绑定的姓名和手机号；如需更正，请联系管理员或通过文末方式联系我们；
2. **删除**：您可联系我们删除您的收藏、留言等记录；
3. **撤回同意**：您可以随时在"我的"页面关闭微信通知订阅开关，撤回对接收订阅消息的同意；撤回同意不影响撤回前基于您的同意已进行的个人信息处理；
4. **注销账号**：您可通过文末联系方式申请注销账号。注销后，我们将删除或匿名化处理您的个人信息，法律法规另有规定的除外；
5. **投诉举报**：如您认为我们的个人信息处理活动侵害了您的合法权益，可向我们或向有关监管部门投诉举报。

## 八、未成年人保护

本小程序面向院内采购相关教职工提供服务，不面向未成年人。我们不会主动收集未成年人的个人信息；如您发现我们无意中收集了未成年人信息，请及时联系我们删除。

## 九、政策的更新

我们可能根据法律法规变化或业务发展需要适时修订本政策。修订后的政策将在本小程序内公示，并在显著位置提示您。您在政策变更后继续使用本小程序，即视为接受修订后的政策。
